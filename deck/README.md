## 主辦方照片（不要公開）

第 1、11 頁用了主辦方資料集的照片（`src/img/crash1.png`、`crash2.png`、`tidy1.png`、`tidy2.png`，裁成取車／還車、前座／後座各一張並遮蔽車牌，存成 `src/img/crash1_pickup.jpg` 等 8 張）。主辦方 README 規定資料只能用於本競賽、未經書面同意不得公開，所以：

- 這些圖檔和產生出來的 `pptx`、`pdf` 都已加進 `.gitignore`，**不要推到 GitHub**。
- 簡報繳交給主辦方沒有問題；要放到公開的地方前，先拿掉第 1、11 頁的照片或向主辦方確認。

## 字型

簡報用微軟正黑體（Microsoft JhengHei）。附的 PDF 是在沒有微軟正黑體的環境輸出的，用的是外觀相近的 Noto Sans CJK TC。用 PowerPoint 開 pptx 再另存 PDF，就會是微軟正黑體；存之前翻一遍確認沒有換行跑掉。

## 重新產生

```bash
cd deck/src
npm install
npm run build            # 輸出 ../iRent+_解決方案.pptx
```

文字、數字、版面都在 `build.js`。手機與後台畫面（`src/img/*.png`，除了 crash、tidy 開頭的）是用影片的示意畫面元件輸出的，沒有使用主辦方照片：

```bash
cd video/remotion
node deckshots/render.mjs ../../deck/src/img
```

`admin_crop.png` 是 `admin.png` 裁掉網址列後的範圍（x 260–2520、y 316–1876）。
